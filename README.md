## Podcast API (podcast-api)

An API for developers to get information on over 4 million podcasts, 180 million episodes, and 1.5 million transcripts. Powered by Taddy's GraphQL API, the Podcast API supports search across podcast series, episode details, transcripts, top charts, popularity data, and webhook subscriptions.
