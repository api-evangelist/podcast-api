# Podcast API GraphQL API

An API for developers to get information on over 4 million podcasts, 180 million episodes, and 1.5 million transcripts. Powered by Taddy's GraphQL API and supports search across podcast series, episodes, transcripts, top charts, and webhook subscriptions.

**Endpoint:** https://api.taddy.org

**Documentation:** https://taddy.org/developers/podcast-api

**GraphQL Properties:**

- GraphQL: https://taddy.org/developers/intro-to-taddy-graphql-api
